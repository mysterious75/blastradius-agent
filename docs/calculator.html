Formulas

Shown so you can check the arithmetic rather than take it on faith. These mirror blastradius/contagion/scoring.py exactly.

blast_radius(token)   = all nodes reachable along damage edges (hop ≤ depth)
reachable_tvl         = Σ TVL of affected nodes (deduplicated)
decayed_tvl           = Σ TVL × 0.65hop
bad_debt             = debt_against_token × (1 − price_ratio)
uncovered_loss       = max(0, bad_debt − backstop_buffer)
liquidatable         = bad_debt ≤ 0
Known limitation, stated plainly: safety-module / backstop balances are not published by any free API, so every live-ingested market carries backstop_buffer_usd = 0. That makes uncovered_loss an upper bound, not a forecast.
