# Research scripts (archival)

One-off corpus acquisition and probing scripts kept for provenance. They are
not imported by the package and are not part of CI. Outputs are written to
`reports5000/` and `learningfromreport/`, which stay local/ignored.

These scripts were moved out of the repository root to keep the production
tree focused; hardcoded developer-machine paths were replaced with paths
resolved relative to the repository.
